What Is SQL?

SQL (Structured Query Language) is the language used to talk to databases. It lets you retrieve, filter, sort, count, and combine data stored in tables.

SQL — Your first query
SELECT * FROM customers;
SELECT name, age, city FROM customers;

Filtering, Sorting & Aggregating

SQL — WHERE, ORDER BY, GROUP BY
-- Filter rows
SELECT * FROM customers WHERE age > 25 AND city = 'Sydney';

-- Sort results
SELECT name, age FROM customers ORDER BY age DESC LIMIT 5;

-- Count per group
SELECT city, COUNT(*) AS customer_count
FROM customers
GROUP BY city
HAVING COUNT(*) > 10
ORDER BY customer_count DESC;

Combining Tables — JOIN

SQL — INNER JOIN
SELECT customers.name, orders.product, orders.amount
FROM customers
INNER JOIN orders ON customers.id = orders.customer_id;

-- LEFT JOIN keeps all customers (even with no orders)
SELECT customers.name, orders.product
FROM customers
LEFT JOIN orders ON customers.id = orders.customer_id;
WHERE vs HAVING: WHERE filters rows before grouping. HAVING filters groups after aggregation.
